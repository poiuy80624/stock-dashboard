加權指數

台指期為日盤、成交量最大的合約（通常為近月），換月日的漲跌幅會包含合約轉換的價差。美股指數的日期為美國交易日，與台股日期並不對齊。「那斯達克指數」為那斯達克綜合指數（^IXIC）。卡片顯示所選期間最後一個有資料的交易日。

個股三大法人買賣表

單位：張（1 張 = 1,000 股）。外資 = 外資及陸資 + 外資自營商；自營商 = 自行買賣 + 避險。買賣超為正（買超）以紅色、為負（賣超）以綠色顯示。表格由新到舊排列。

外資持股表

表格顯示所選期間「最後一個交易日」的持股，並與期間內前一個交易日、期間第一個交易日比較。點選表格中的股票可查看外資持股比例走勢。持股比例 = 外資及陸資持有股數 ÷ 發行股數；可投資比例 = 尚可投資的比例。

整體三大法人買賣表

單位：億元（買賣金額）。外資 = 外資及陸資 + 外資自營商；自營商 = 自行買賣 + 避險。買賣超為正以紅色、為負以綠色顯示。表格由新到舊排列。
